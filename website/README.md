# Publish the coursework website

The page is ready in `index.html`. It links to the public coursework and uses no passwords, private information, or additional packages.

1. Sign in to GitHub and create a **public** repository named exactly `KevinSun2.github.io`.
2. Upload this folder's `index.html` to the root of that repository. Use the commit message `Add analytics coursework portfolio`.
3. In that repository, open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
5. Wait for the deployment, then open <https://kevinsun2.github.io> and check the coursework links.

The website has not been published or verified online yet.
